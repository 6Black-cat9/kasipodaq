Chromium браузерінде әкімшінің 12 беті және мүшенің 4 беті ашылды. Нақты мүше өтініш берді, әкімші мәртебесін өзгертіп жауап жазды, мүше өзгерген мәртебені көрді. MEMBER әкімші маршрутына кіргенде 403 беті ашылды. Desktop және 390 px mobile көріністерінде көлденең асып кету анықталмады; mobile мәзірі мен өтініш кестесі жұмыс істеді. Пайдаланушы сценарийлерінде JavaScript қателері тіркелмеді.

Әкімші интерфейсінде жаңа мүшені қосу, жергілікті суретпен жаңалық жариялау және толық бетін ашу, PDF құжатын жүктеу және оның мазмұнын қайта жүктеп алу, іс-шара қосу, растау терезесі арқылы жою да тексерілді. Барлығы нақты API мен PostgreSQL арқылы орындалды.

Күн атаулары браузер ICU деректеріне тәуелсіз тексерілді: «5 қазан 2026», «қаз», «05.10.2026», «29 ақпан 2024». Нақты seed PDF файлы жүктеліп, PDF сигнатурасы тексерілді.

Автоматты тесттер жеке PostgreSQL дерекқорындағы уақытша schema қолданады. Браузер тексеруінде жасалған уақытша жазбалар мен файлдар тазаланды. Нақты мектептің деректері енгізілмеген; бастапқы деректер seed-тен келеді.

Қайта тексеру:

```bash
npm run lint
npm run build
npm test
npm audit
```

Production контейнер жергілікті ортада тексерілді. Қоғамдық доменге жариялау орындалмаған; Docker Compose немесе README командаларымен іске қосуға болады.
